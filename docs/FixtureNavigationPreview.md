# Fixture Navigation Preview

The public fixture home page in `fixture/pages/indexPage.ts` includes quick-access links for the local Adminizer demo and the public GitHub repository:

- `Open Adminizer` opens the local fixture admin UI.
- `View on GitHub` opens the Adminizer repository at `https://github.com/adminization/adminizer`.

This keeps the fixture landing page useful both as a demo entry point and as a reference page for the project source.
