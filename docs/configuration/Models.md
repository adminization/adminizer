# Модели

Раздел `models` описывает сущности, доступные в панели. Для каждой модели можно включать действия:

- `list` — список записей с фильтрами и пагинацией;
- `add` — создание записей;
- `edit` — изменение существующих данных;
- `view` — просмотр одной записи;
- `remove` — удаление записи.

Минимальная конфигурация модели:

```js
module.exports.adminpanel = {
  models: {
    users: {
      title: 'Users',
      model: 'User',
    }
  }
};
```

Действия могут быть отключены булевым значением или иметь собственные опции.

```js
models: {
  users: {
    list: { limit: 20, fields: {} },
    edit: false,
  }
}
```

Модель можно скрыть из меню через `hide: true`. Для глобального исключения полей используйте `fields` на уровне модели.
