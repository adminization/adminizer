# Виджеты дашборда

Виджеты отвечают за содержимое главной страницы панели. Существует несколько типов виджетов:

| Тип | Описание |
|-----|----------|
| `info` | Отображает текстовую информацию. Метод `getInfo()` возвращает строку для показа. |
| `switcher` | Управляет бинарным состоянием. Имеет методы `getState()` и `switchIt()` для изменения значения. |
| `action` | Выполняет произвольное действие по клику. Определяется методом `action()`. |
| `link` | Набор ссылок для перехода на другие страницы. Метод `getLinks()` возвращает список ссылок. |
| `custom` | Пользовательский виджет на основе собственного JS‑модуля. Указывает пути к скриптам через `jsPath`. |

Пример подключения виджетов по умолчанию:

```ts
import { AdminizerConfig } from "adminizer";

const config: AdminizerConfig = {
  routePrefix: "/admin",
  dashboard: {
    autoloadWidgetsPath: "widgets",
    defaultWidgets: ["stats", "latest"],
  },
  models: {},
};
```
