# Getting started

Welcome to the Adminizer demo knowledge base. This document is bound to the
dashboard URL, so the contextual documentation of the dashboard includes it.

## Navigation

Use the sidebar to open model sections, catalogs and tools. Every entry you
see is filtered by your access rights.

## Widgets

The dashboard is assembled from widgets. Switchers toggle things on and off,
info widgets show numbers, action widgets run one-off commands.

See also [models-guide](models-guide) for working with data models.

And [project-graph](project-graph) shows what per-project access rights feel like
from the inside.
